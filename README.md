# Favorite Dessert Records is a web form that allows users to enter their name, favorite dessert, and chocolate preference. The information is saved in a database. The saved records are displayed in a table and where users can edit or delete existing records.
# In order to run the application, you will need to have Visual Studio installed and a SQL Server database configured.
# Open the solution file in Visual Studio, File > Open > Website, and then select the Execute green arrow button or IIS express button.
# Main Features: 
# - Enter name, favorite dessert, and chocolate preference
# - Save records to a SQL Server database
# - View saved records in the table 
# - View, edit, or delete existing records
